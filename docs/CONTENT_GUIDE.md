# 内容配置指南

## 工具收录

首发工具应具备较高认知度、代表明确使用场景、形成有趣组合，或对身份识别有明显贡献。不得依据参数排行决定收录。

首发 41 款：

- 通用：ChatGPT、Claude、Gemini、DeepSeek、豆包、Kimi、通义千问、Grok、Microsoft Copilot、腾讯元宝、文心一言。
- 研究：Perplexity、NotebookLM、Genspark、秘塔AI搜索。
- 编程：Codex、Claude Code、Cursor、GitHub Copilot、Windsurf、Replit Agent。
- 图像：Midjourney、ChatGPT Images、Gemini Image、即梦AI、ComfyUI。
- 视频：Seedance、Sora、Veo、可灵AI、Runway、海螺AI、PixVerse。
- 音频：Suno、Udio、ElevenLabs。
- Agent：Manus、Coze、Dify、n8n、Zapier。

## 命名与搜索

- 主名称使用稳定品牌或产品名，不包含易过期版本号。
- 每款工具可配置多个中英文别名。
- 搜索不区分大小写，支持中英文混合。
- 工具卡定位必须短、清楚，不写未经证实的能力结论。

## 标签

场景标签包括通用对话、搜索、研究、编程、代码 Agent、图像、视频、音频、工作流、智能体、本地部署、节点工作流、无代码和内容生产。

风格标签包括极简、折腾、工程、创作、研究、自动化、多模型、专业工具、一站式和工作流。

产品形态标签包括网页、桌面、IDE、API、开源、闭源、国内和海外。“国内/海外”仅供组合判断，不表达价值高低。

## 称号与判词

- 每个特殊称号必须有明确、可测试的配置条件。
- 每个称号至少提供 3 条判词，由稳定哈希选择。
- 语气应准确、有趣、适合分享，避免羞辱、歧视或虚假权威感。
- 不声称科学分析人格、权威评测能力或判断产品优劣。
- 辅助标签使用两个简短短语，如“工程重度”“自动化上瘾”“视觉优先”。

## 固定声明

结果页应展示：

> 六维结果根据所选工具的主要用途进行娱乐化计算，不代表工具能力排名。

隐私说明应明确：无需注册；选择与结果默认只保存在当前浏览器；分享链接仅包含公开工具 ID 和本命工具 ID。
