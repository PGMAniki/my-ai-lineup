# 评分与结果规则 v1

## 六个维度

- `expression`：思考表达。
- `research`：搜索研究。
- `coding`：编程开发。
- `image`：图像设计。
- `media`：影音创作。
- `automation`：Agent 自动化。

工具在每个维度配置 0–5 的编辑分值。分值仅表达大众认知中的主要用途，不是能力排名或 Benchmark。

## 选择校验

- 工具数量必须为 3–8。
- 工具 ID 必须存在且不得重复。
- 本命必须存在，并且属于已选工具。
- 非法输入必须返回明确错误，不得静默修正。

## 六维计算

每个维度独立计算：

1. 普通工具使用基础分；本命工具乘以 1.25，最高调整分为 6.25。
2. 只取该维度最高的 3 款；不足部分按 0。
3. 有效分：第一名×55% + 第二名×30% + 第三名×15%。
4. 最终分：`round(有效分 / 6.25 × 100)`，限制为 0–100。

工具输入顺序不得影响分数。六维最高的两个维度作为主、次维度；平分时必须使用固定维度顺序打破平局。

## 称号匹配优先级

1. 具体工具组合。
2. 特殊标签组合。
3. 阵容结构。
4. 主维度组合。
5. 单主维度。
6. 通用兜底。

规则配置包含 `priority`，按优先级降序匹配，命中第一条即停止。相同优先级必须以稳定、明确的次序决定。

## 稳定结果

- 稳定哈希由规则版本、排序后的工具 ID 和本命 ID 生成。
- 同一集合不受选择顺序影响。
- 判词从称号候选列表中依据稳定哈希选择，不使用 `Math.random()`、时间或网络。
- 核心算法不得访问 DOM 或 LocalStorage。

## 分享参数

格式：`/#/result?v=1&t=chatgpt,codex,midjourney&c=codex`

- `v`：规则版本。
- `t`：工具 ID 列表。
- `c`：本命工具 ID。

链接只包含公开工具 ID，不包含身份信息。解析时校验版本、数量、重复、未知工具和本命归属。

## 必测场景

- 本命加权正确。
- 每维只取前三名且分数在 0–100。
- 工具顺序不影响结果。
- 同一阵容结果稳定。
- 少于 3、多于 8、未知工具、重复工具或缺少本命时拒绝生成。
- 高优先级规则先命中；无特殊规则进入维度兜底。
