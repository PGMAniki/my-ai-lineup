# UI 与交互规格

## 视觉方向

定位为“数字人才档案 + AI 战队名单 + 轻赛博编辑设计”。避免二游卡池、稀有度边框、重霓虹粒子、复杂 3D、科技大屏和大量玻璃拟态。

基础色：

- 背景：`#0B0D12`
- 一级表面：`#141821`
- 二级表面：`#1B202B`
- 主要文本：`#F6F7F9`
- 次要文本：`#9AA3B4`
- 主强调色：`#84FF6A`
- 辅助蓝色：`#7A9CFF`
- 警示色：`#FFB454`
- 边框：`rgba(255,255,255,0.10)`

使用系统字体，不加载大型中文字体。页面宽度适配 320、375、390、430px；PC 居中容器最大宽度 520px。

## 首页

目标：3 秒内理解玩法，主按钮首屏可见。

- 标题：组建你的AI阵容
- 副标题：选出你真正使用的AI工具，看看你是哪种AI玩家。
- 示例：5 个示例工具、示例称号和静态雷达装饰。
- 主按钮：开始组队。
- 说明：无需登录，不收集个人信息，结果仅供娱乐。

不放启动动画、轮播、长规则、用户数量、排行榜或虚构数据。

## 选择页

- 顶部：返回、标题“选择你的AI工具”、已选数量。
- 提示：只选真正使用过并愿意放进日常工作流的工具。
- 搜索：支持中英文别名且不区分大小写。
- 分类：全部、通用、研究、编程、图像、视频、音频、Agent。
- 工具网格：移动端每行 2 张卡片。
- 卡片：原创徽章、名称、短定位、边框高亮和勾选标记。
- 固定底栏：已选阵容、数量和“生成我的AI身份”。
- 少于 3 款时按钮禁用并提示还差几款；第 9 款使用轻提示，不替换已有选择。

## 本命选择层

- 标题：谁是你最离不开的AI？
- 说明：本命会对最终结果产生更高影响。
- 只展示已选工具；必须选择后才能确认。
- 按钮：就是它，生成结果。

## 结果页

顺序：产品小标题、身份称号、判词、本命、六维图、辅助标签、完整阵容、说明、分享、返回修改、娱乐声明。

首屏应看到称号、判词、本命、雷达图主体，并能感知分享入口。主要按钮顺序：生成分享图、复制结果链接、修改阵容、重新开始。

生成动画约 1 秒，并支持 `prefers-reduced-motion`；不得伪装成复杂 AI 分析。

## 分享图

- 1080×1440，3:4，PNG 或高质量 JPEG。
- 包含产品名、称号、判词、本命、雷达图、六维数值、阵容、标签、二维码、短域名和娱乐声明。
- 微信内提示长按保存；普通浏览器提供保存操作；失败时允许截图兜底。

## 兼容与无障碍

- 重点测试微信内置浏览器、iOS Safari、Android Chrome/WebView 和常见国产浏览器。
- 固定底栏处理 `env(safe-area-inset-bottom)`。
- 点击区域至少 44×44px。
- 颜色不是唯一的选中提示；按钮和卡片有可读文本。
- 支持基础键盘操作与减少动画偏好。
