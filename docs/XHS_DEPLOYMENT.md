# 小红书小工具部署

## 产品差分

小红书小工具是纯本地离线 H5 容器，与公开 H5 复用业务核心，但必须遵守 `.codex/` 内官方构建 Skill：

- 不联网，不加载外部脚本、图片、字体或媒体。
- 不使用剪贴板、文件下载、外链跳转、Worker、WebAssembly 或动态执行代码。
- 资源全部使用包内相对路径。
- `index.html` 必须位于 ZIP 根目录。
- 分享图不含二维码、网址或外部导流链接。
- 分享图在阵容标题行以低视觉权重显示“小红书搜索「刘道理」”。
- 用户进入无控件截图模式后，使用系统截图保存。

## 构建与校验

```text
npm run package:xhs
```

命令依次执行：

1. Vue/TypeScript 构建。
2. 检查入口、文件类型、相对路径和 viewport。
3. 扫描网络、剪贴板、下载、外链、Worker、WASM、动态执行等禁用能力。
4. 将 `dist/xhs` 的内容直接压缩到 ZIP 根目录。

目标产物：

```text
artifacts/my-ai-lineup-xhs.zip
```

## 上线前验证

- 在 PC 模拟器检查首页、选择、本命、结果和截图模式。
- 在真机检查安全区、滚动、软键盘、Canvas 中文与本地存储。
- 确认截图模式无按钮、二维码、网址和 H5 署名。
- 确认容器控制台没有 CSP、网络或禁用 API 错误。
- 通过后再上传正式包并提交审核。
