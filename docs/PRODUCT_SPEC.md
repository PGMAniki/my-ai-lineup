# 《我的AI阵容》产品规格 v1.0

## 产品定义

- 形态：移动端优先的静态 H5。
- 一句话玩法：选出真正使用的 AI 工具，指定一款本命，生成 AI 身份和六维能力版图。
- 核心传播物：可独立看懂的结果图片，以及可还原阵容的分享链接。
- 数据原则：本地计算、本地存储、无需登录、无业务后端。

## 产品目标

首发版本只验证四件事：

1. 用户能快速找到自己使用的工具。
2. 结果与选择之间存在明显联系。
3. 称号足够准确或有趣，能激发分享意愿。
4. 结果图脱离 H5 后仍能被看懂。

## 用户链路

1. 首页理解玩法。
2. 进入选择页，选择 3–8 款真正使用的工具。
3. 从已选工具中指定一款“最离不开的 AI”。
4. 本地生成六维分数、称号、判词和标签。
5. 查看结果，生成分享图或复制结果链接。
6. 可返回修改阵容或重新开始。

分享链接打开时先展示分享者结果，不覆盖访问者的本地历史选择。

## 页面与路由

- `/`：首页。
- `/select`：工具选择页。
- `/result`：结果页。
- 本命选择和分享图预览使用页内弹层，不新增路由。

## MVP 必须完成

- 首页、选择页、结果页。
- 41 款首发工具；分类、别名搜索和 3–8 款限制。
- 本命选择、六维评分、稳定称号和判词。
- 不少于 30 个特殊称号及双维度兜底称号。
- SVG 雷达图。
- 1080×1440 Canvas 分享图及二维码。
- Hash 结果链接与规则版本。
- LocalStorage 持久化。
- 核心算法单元测试。
- Cloudflare Pages 静态部署。

## 明确不做

- 登录、头像、昵称、手机号、OpenID、用户画像。
- 后端、数据库、服务端阵容存储、远程动态配置。
- AI API、科学人格测试、能力排行榜、好友关系、全服排行。
- 评论、UGC、自定义工具提交、会员、广告、付费、任务系统。
- 强制分享、分享解锁、多语言、多套海报、小程序首发版。

## 本地数据

键名：

- `ai-lineup:v1:selection`
- `ai-lineup:v1:last-result`
- `ai-lineup:v1:preferences`

只保存工具 ID、本命 ID、上次结果、引导状态和减少动画偏好。不得保存身份、设备指纹、位置、通讯录、剪贴板或广告标识。

## v1.0 冻结决策

- 主动选择，不做抽卡。
- 选择 3–8 款工具，必须指定 1 款本命。
- 六个维度；本命权重 1.25；每维只取最高 3 款。
- 全部结果本地、确定性生成，不调用 AI。
- 首发 41 款工具、至少 30 个特殊称号。
- 页面雷达图使用 SVG，分享图使用 Canvas，比例 3:4。
- 使用 Hash 结果链接、Vue 3 + Vite + TypeScript。
- 首发部署 Cloudflare Pages，小程序仅作为后续载体。
